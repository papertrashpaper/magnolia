# 長期計画の候補生成・評価の診断

2026-10-09。現在の41種類・102枚。2人・5人の中盤/終盤、別配札による64局面。追加目標OFF。方法は [METHOD.md](METHOD.md)。各候補は選択用3通りと独立評価用3通りで処理し、各局面の既存10候補と追加6候補を記録した。

今回の範囲では、追加6計画が既存候補より良い参考上限を示した局面はなく、候補追加の効果は限定的だった。配札3通りへの増加にも安定した改善は確認できない。次の研究では、計画名を増やすより、現在の手札と盤面に合わせた配置順の生成を優先する。ただし、今回の結果から他の長期戦略そのものが弱いとは結論できない。

## 候補生成と選択の観察

独立評価で追加候補の最高値が既存候補の最高値を上回った局面は0/64。このうち追加候補を選ばなかったのは1通り評価で0件、3通り評価で0件。追加候補を選んだ結果、同じ評価通り数の既存候補の選択より独立評価が下がったのは1通りで1件、3通りで0件。

独立評価自体の最高値を選んだ参考上限は楽観的。3通りの仮想配札内の観察であり、良い計画が存在しないことや評価の真の誤りを証明するものではない。候補を追加しただけでは採用候補の質が保証されず、複数配札の評価も局面によって選択を変える。

## 診断例

差が最も悪かった例と、追加候補の参考上限が最も高かった例を、勝敗ではなく診断値から選ぶ。全例はsummary.jsonに記録。

- 配札1030000、2人、ラウンド2：既存3通りがwar、追加3通りがwarを選択。独立評価差0.00。追加候補の参考上限差-4.00。
- 配札1030003、2人、ラウンド4：既存3通りがplan-0、追加3通りがplan-0を選択。独立評価差0.00。追加候補の参考上限差0.00。

## 検証と限界

既存候補の評価が元のchoosePlanningと一致すること、入力を変更しないこと、実際の相手手札を変えても結果が変わらないことをテストした。全64局面で16候補×6配札の合法性とカード枚数を検査。代表2局面を再実行し、時間以外の全記録が一致。原始記録と枚数・ソースのSHA-256を保存した。欠測は0局面。

均衡評価型が作った局面に限定した診断で、全局面や人間のプレイを代表しない。実対戦の勝率比較ではない。独立評価も3通りしかなく、相手モデルや4ラウンドの制限は残る。採用した計画を仮想対戦では継続するため、実際に毎判断で再計画するCPUへの効果は別に検証が必要。ゲーム内CPUを変更していない。

再現：

```sh
node scripts/run-planning-diagnosis.mjs
node scripts/run-planning-diagnosis.mjs --validation
node scripts/analyze-planning-diagnosis.mjs --replay
```

分析は圧縮記録からもハッシュを照合して実行できる。

## 検証・再現

全19735配置で48通りの終局を処理し、毎回102枚の保存を検査した。合法手は即時効果・揃いによる支払い能力の変化を反映し、0〜2枚の全順序・座標を列挙。手札の同名コピーや同じ結果になる配置も記録に残すため、行動数は異なる戦術の数ではない。通常のsubmitによる同時解決との一致、相手実手札への非依存、独立検証を選択に使わないことをテスト。代表2局面の再実行が時間以外で一致した。原始記録と圧縮記録のハッシュを保存。

相手の配置方針は、注目プレイヤーの予定配置を見る前の公開状態で決める。サンプルは終局が保証される局面を条件に選んだもので、全対戦に対する出現率や平均勝率を表さない。仮想相手の方針・手札推定、注目手札の有限な評価回数による不確実性は残る。

```sh
node scripts/run-endgame-decisions.mjs
node scripts/run-endgame-decisions.mjs --validation
node scripts/analyze-endgame-decisions.mjs --replay
```

圧縮分割記録だけでも再集計できる。ゲーム内CPUは変更していない。
